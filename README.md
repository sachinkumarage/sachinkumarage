# Hi, I'm Sachin Kumarage 👋

### Materials Engineer · Characterization · Failure Analysis · NDT · Scientific Python for Metallurgy

I'm a Materials Engineer (B.Sc. Eng. Hons, Materials Science & Engineering, University of Moratuwa).

At **SRIQE** I work hands-on with natural sapphire (corundum): mineral identification, heat treatment and non-destructive evaluation of high-value stones. Earlier, at **NBRO**, I supported R&D on national building-materials standards using mechanical testing and SEM.

Alongside that, I build **open-source Python tools** that make materials engineering calculations fast, visual and reproducible.
